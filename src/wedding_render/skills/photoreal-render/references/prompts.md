# 照片级化 Prompt 模板库

结构（photoreal.py 自动组装，本文件供人工调优与新增模板）：

```
[角色] 把婚礼现场布局示意图转成照片级真实的婚礼现场照片
[锁布局] 严格保持物体位置/数量/比例/透视/机位不变 …
[氛围] {时段模板}
[区域描述] {仪式区|晚宴区 模板，由 layout JSON 派生}
[材质翻译] 见 blender/semantic_palette.md
[质量] 花艺自然舒展、材质细节丰富、景深自然、8k 婚礼实拍质感
[风格参考]（有 --refs 时）只取参考图风格与花材感觉，布局以输入图为准
```

## 时段模板

- **day**：正午前后明亮的自然日光，蓝天白云，海风清透
- **dusk**：三亚黄昏 golden hour，暖橙色斜阳，粉橘色晚霞，串灯已点亮（默认）
- **night**：入夜海滨草坪，深蓝夜空，串灯与烛光为主要光源，温馨浪漫

## 区域模板（可复制修改）

### 仪式区 · 白绿清新
> 仪式区：柔软的白色纱幔与白玫瑰/白桔梗拱门花艺，自然舒展的绿植叶材（尤加利、龟背竹）；白色婚礼椅，通道散落白色花瓣。

### 仪式区 · 香槟金复古
> 仪式区：香槟金玫瑰与干花拱门，铁艺拱架，暖金烛台沿通道两侧排列，复古欧式氛围。

### 晚宴区 · 月下花影
> 晚宴区：2 张长桌，垂坠感米白桌布，桌面绿植花艺带与烛台；头顶之字形暖黄串灯已点亮，入夜海滨草坪氛围。

### 晚宴区 · 四季与你
> 晚宴区：长桌以时令鲜花桌花为核心，色彩明快自然，白天草坪上的轻松花园晚宴。

## 修正路由用追加语（review.py 评分低时）

- 布局漂移：`【再次强调】任何物体不得移动、增删、缩放；输入图的透视与构图是唯一的布局依据。`
- 真实感不足：`模拟全画幅相机 50mm 焦段实拍，自然景深，避免插画感与过度饱和。`
- 风格不匹配：`严格贴近参考案例图的花材种类、色彩配比与形态密度。`
