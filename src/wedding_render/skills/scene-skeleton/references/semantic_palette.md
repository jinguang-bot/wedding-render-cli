# 材质色块语义对照表（骨架渲染 ↔ 照片级化 prompt 翻译）

骨架渲染图中的色块不是最终外观，而是给生图模型的**材质指令**。photoreal.py 按
本表把色块自动翻译成自然语言描述。

| 色块（材质名） | 颜色 | 含义 | 照片级化翻译 |
|---|---|---|---|
| `white_cloth` | 纯白 | 纱幔、白花、白椅 | 柔软的白色纱幔与白玫瑰/白桔梗花艺，哑光织物质感 |
| `greenery` | 中绿 | 叶材、花植 | 自然舒展的绿植叶材（尤加利、龟背竹、蕨类），清透有层次 |
| `warm_light` | 暖黄（自发光） | 灯串、烛光 | 点亮的暖黄串灯与蜡烛，黄昏氛围，光斑柔和 |
| `floor_light` | 浅石色 | 石材地面/步道 | 浅色石材地面与石板步道 |
| `wood` | 木色 | 家具、地板、杆件 | 原木质感家具/木地板，浅色橡木 |
